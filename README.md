# Дарлу — сайт-агрегатор нишевых подарков

- `docs/` — сам сайт (HTML/CSS/JS), `docs/img/` — фото товаров
- `server/app.py` — маленький сервер: отдаёт сайт и ИИ-разбор человека (`/api/profile`)

## Запуск с ИИ-помощником
```bash
cd server && cp .env.example .env     # вписать ANTHROPIC_API_KEY=... (файл .env не попадает в git)
cd .. && python3 server/app.py        # открыть http://localhost:8000
```
Без ключа сайт работает: ИИ-разбор недоступен, помощник задаёт вопросы и разбирает текст простым поиском слов.
Модель по умолчанию — `claude-haiku-5-5` (дешёвая, умеет читать скриншоты); сменить можно через `MODEL=` в `.env`.

## Только посмотреть сайт (без ИИ)
```bash
python3 -m http.server 5173 --directory docs
```

## Личный кабинет
Регистрация и вход по почте и паролю (`docs/account.html`). Данные лежат в `server/data.db` (SQLite, не попадает в git):
пароли хранятся только как хеш (PBKDF2-SHA256), сессия — в HttpOnly-куке на 30 дней. В кабинете есть избранное;
гостевое избранное хранится в браузере и после входа переносится в аккаунт. Кабинет работает только при запущенном `server/app.py`.

## Публикация (GitHub Pages)
Папка `docs/` публикуется прямо из ветки `main`: Settings → Pages → Source «Deploy from a branch», ветка `main`, папка `/docs`.
Адрес будет вида `https://<логин>.github.io/darlu/`. На статическом хостинге нет сервера, поэтому аккаунты, ИИ-разбор профиля и
отправка заявок с сайта не работают: кабинет показывает «скоро появится», форма брендов открывает письмо в почте, подбор идёт по вопросам.
